⚙️ TMDB API Configuration

Your API token is saved directly in your browser's private localStorage. It is never sent to any server other than directly to TMDB.

Where do I get my token?
Log in to TMDB, visit Settings > API ↗, and copy your API Read Access Token (recommended v4) or API Key (v3).
